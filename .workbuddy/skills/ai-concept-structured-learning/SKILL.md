# 通用AI概念结构化学习生成技能

## 概述

接收任意 AI 领域相关概念作为输入主题，自动生成符合规范的标准化学习资料、概念关联说明与交付指引，支持知识沉淀与复用。

## 触发条件

当用户提出以下类型请求时，加载本 Skill：

- "帮我学习/讲解 XX 概念"（XX 为任意 AI 领域概念）
- "生成 XX 的学习笔记/学习资料"
- "XX 是什么、怎么用、有什么坑"
- 批量生成 AI 概念培训材料的任务

## 适用场景

1. 新的 AI 概念入门学习、个人知识体系搭建场景
2. 团队内部 AI 基础能力培训材料批量生成
3. AI 项目文档里的核心概念说明补全
4. 任意需要结构化输出 AI 概念完整说明的生产场景

## 输入信息要求

- **必需**：1 个待学习的目标 AI 概念名称
- **可选**：概念所属领域、内容侧重方向（偏原理 / 偏落地应用）

## 生成执行步骤

按顺序执行以下五步：

### 第一步：检索与通俗化定义

全网检索该概念的权威定义、行业通用解释、最新官方说明，整理出符合普通人理解的非晦涩个人解释。

### 第二步：机制拆解

拆解概念的核心运行机制、组成模块、关键工作逻辑，用通俗类比完成拆解，**避免照搬学术论文原文**。

### 第三步：设计落地案例

结合实际产研场景，设计 1 个可落地的真实应用案例，包含三个部分：

1. 场景背景
2. 执行流程
3. 落地效果

### 第四步：误区与边界梳理

梳理该概念最常见的认知误区、和易混淆同类概念的差异、实际使用时的边界限制。

### 第五步：查找核验资料

查找 3 个以上可直接访问的公开权威资料链接，包括官方文档、行业白皮书、技术博客等，作为内容核验来源。

## 标准输出结构

单份概念学习资料固定输出以下模块：

```
《【概念名称】学习笔记》

概念个人解释：xxx
核心机制与组成：xxx
实际应用场景：xxx
易混淆问题与使用边界：xxx
参考核验链接：xxx
```

## 资料来源要求

- 优先选取发布时间在**近 2 年内**的行业公开资料，避免过时的旧定义
- 优先选用：大模型厂商官方文档、头部企业官方技术博客、认证技术专家专栏、正规技术出版社公开内容链接
- **禁止**引用无来源的自媒体杂谈内容

## 自检校验规则

生成完成后必须逐项核对以下条目，**全部满足才可交付**：

- [ ] 没有照搬公开资料的大段原文，所有解释都完成通俗化重构
- [ ] 应用场景是真实可落地的场景，不是空泛的理论描述
- [ ] 使用边界部分至少说明 2 条该概念不能做到的事情，避免过度神化效果
- [ ] 所有资料链接都可以直接点击访问，没有失效域名
- [ ] 没有出现当前时间节点之后的未发布内容，时间逻辑符合当前时间

## 示例

**用户**：帮我学习一下 RAG 这个概念，偏落地应用。

**Agent**：按本 Skill 五步流程执行——检索 RAG 权威定义并通俗化 → 拆解检索增强生成的机制（类比：开卷考试）→ 设计客服知识库问答案例 → 梳理"RAG 不是微调"等误区与边界 → 附 3 个以上权威链接 → 逐项自检后按标准结构输出《RAG 学习笔记》。
